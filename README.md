# My Store Manager — Android V2.0

A standalone offline Android store-management app.

## Included
- Dashboard
- Product CRUD
- Stock quantity
- Low-stock warning (<= 5)
- SKU/barcode field
- Purchase and selling price
- Billing / checkout
- Automatic stock deduction
- Sales history
- Profit calculation
- Local offline storage
- Backup JSON copied to clipboard

## Build
1. Open this folder in Android Studio.
2. Let Android Studio download the Android Gradle Plugin/Kotlin/Android dependencies.
3. Select **Build > Build APK(s)**.
4. The APK will be under `app/build/outputs/apk/debug/`.

Minimum Android version: Android 7.0 (API 24).

This source project is provided as a complete Android Studio project. A compiled APK is not included.
